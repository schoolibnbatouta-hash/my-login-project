# 🎮 Portal Authorization Interface

A dark-themed, ultra-sleek user authorization interface concept designed with a premium gaming aesthetic. This project features a responsive login flow complete with input layouts, credential styling, a custom simulated Google OAuth button, and integrated credential recovery handling.

---

---

## ✨ Features

*   **Premium Gaming Aesthetic:** Implements a deep custom radial background gradient (`#2b0c0a` to `#050508`) with centered modern UI card containers.
*   **Complete Authentication Flow:** Structured multi-page navigation layout connecting the main entry portal directly to a dedicated verification layer (`reset.html`).
*   **Interactive JavaScript Alerts:** Embedded DOM interaction handling user-side responses upon form execution.
*   **Modern Form Elements:** Styled data fields utilizing customized placeholder properties, padding distribution, and dark-mode native input aesthetics.

---

## 🛠️ Tech Stack & Architecture

*   **Frontend Structure:** HTML5 (Semantic document construction)
*   **Component Styling:** Vanilla CSS3 (Inline style processing, flexbox distribution, viewport scale values)
*   **Behavioral Logic:** Native JavaScript (Asynchronous client-side alerting & routing handlers)
